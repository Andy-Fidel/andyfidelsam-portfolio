# Andy-Fidel Samuel — Portfolio

A focused, editorial portfolio for full-stack product engineer Andy-Fidel Samuel.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production checks

```bash
npm run lint
npm run build
```

## Deploy to Vercel

Import this repository in Vercel and accept the detected Next.js defaults. No environment variables or external services are required.

The Open Graph image and canonical metadata automatically use `VERCEL_PROJECT_PRODUCTION_URL` after deployment.
